# Banderas / Flags

PNG reales, no emojis ni SVG generados por IA.

- `es`, `gb`, `pt`, `br`, `fr`, `it`: [flagcdn.com](https://flagcdn.com/) (banderas de uso libre).
- `galicia`: [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Flag_of_Galicia.svg) (bandera de Galicia, de uso libre).

Se usan en el selector de idioma con `object-fit: cover` para que todas ocupen el mismo hueco.
